① 시작하기

1 상단 📖 프로젝트 선택에서 작품 선택.
2 ✏️ 회차 입력.
3 단계 자동 추천.

② 작업장 사용법

  • ✍️ 원문: 소설 내용 작성.
  • 📋 체크리스트: 태그로 출처 확인 — 기본, 매화, 문장, 장르, 프로젝트, 이 회차

③ 저장 (★중요★)

💾 오늘 저장 버튼이 유일한 영구 저장 방법입니다.

④ 💾 로컬 파일 저장 (백업)

1 ⚙️ 설정 → 💾 저장위치 클릭.
2 내 컴퓨터에 저장할 폴더와 파일명 지정.

⑤ 📋 기록

  • 날짜별 슬롯 확인, 📂 불러오기, 🗑️ 삭제

⑥ 백업

  • 📤 JSON 내보내기: 모든 데이터(프로젝트·기록·목표·떡밥·메모·체크리스트)를 JSON 파일로 저장
  • 📄 텍스트 내보내기: 기록을 읽기 쉬운 텍스트 파일로 저장
  • 📥 JSON 가져오기: 내보낸 JSON 파일을 불러와 복원 (현재 데이터는 덮어씀)
  • ⚠️ 초기화: 헤더의 초기화 버튼으로 모든 데이터 삭제 (되돌릴 수 없음)

📥 프로그램 파일 다운로드

지금 열려 있는 이 도구를 빈 상태의 단일 HTML 파일로 내려받습니다. 다른 컴퓨터에 옮기거나 백업용 사본을 만들 때 사용하세요. (작성 중인 데이터는 포함되지 않습니다 — 데이터는 📤 JSON 내보내기를 이용하세요.)
